## Project Overview

Portfolio website for a web developer from Kabardino-Balkaria, Russia. The site positions the developer as THE regional web developer with strong Caucasian identity, combining portfolio showcase with a curated travel guide to drive Instagram engagement and recognition.

## Commands

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build

## Tech Stack

- Vite 7.x (vanilla JavaScript, no framework)
- Plain CSS (in `src/style.css`)
- ES modules

## Site Structure (Planned)

1. **Homepage** - Hero with Caucasus imagery, tagline, featured projects
2. **Portfolio/Work** - Case studies with visuals and process documentation
3. **Discover Kabardino-Balkaria** - 10 curated locations with photos/descriptions (Mount Elbrus, Chegem Waterfalls, Blue Lake, etc.)
4. **Contact/Hire** - Clean contact form

## Content Reference

The README.md contains detailed descriptions for all 10 curated Kabardino-Balkaria locations including taglines, descriptions, best times to visit, and access information.
