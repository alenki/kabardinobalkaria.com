# kabardinobalkaria.com

## Философия и Стиль

### Суть Кабардино-Балкарии

Кабардино-Балкария — это не про экстрим и адреналин. Это про **тишину**, **покой** и **красоту**, которая существовала тысячелетиями.

Представь:
- Звук горной реки, бегущей по гладким камням
- Утренний туман, медленно поднимающийся над долиной
- Солнечный свет, мягко освещающий альпийские луга
- Бесконечное небо над снежными вершинами
- Тёплый ветер, несущий запах трав и цветов

Это место, где время замедляется. Где можно просто **быть**.

## Визуальный Стиль

### Цветовая Палитра

```
Основные цвета:
├── Мягкий зелёный (#8BA888) — альпийские луга, леса
├── Небесно-голубой (#A8C5D9) — небо, реки, озёра
├── Тёплый кремовый (#F5F0E8) — солнечный свет, камень
└── Мягкое золото (#E8D4A8) — закатный свет, тепло

Акценты:
├── Лавандовый (#B8A9C9) — горные цветы
├── Глубокий бирюзовый (#5B8A8A) — Голубые озёра
└── Тёплый коричневый (#9C8B7A) — земля, дерево, камень
```

### Атмосфера

- **Мягкость** — никаких резких контрастов, острых углов
- **Воздушность** — много пустого пространства, как горный воздух
- **Плавность** — анимации медленные, как течение реки
- **Тепло** — несмотря на горы, ощущение уюта и гостеприимства
- **Мечтательность** — лёгкая дымка, мягкий фокус, как сон

### Типографика

- Заголовки: мягкая антиква с характером (тёплая, не холодная)
- Текст: читаемый, округлый шрифт с хорошим межстрочным интервалом
- Стиль: спокойный, поэтичный, без агрессии

### UI Элементы

- Скруглённые углы (органические формы)
- Мягкие тени (как утренняя дымка)
- Плавные переходы между секциями
- Изображения с мягкими краями или fade-эффектами

### 2. Природа (`/priroda`)

Сердце сайта. Погружение в природу региона.

**Подразделы:**
- **Горы** — Эльбрус, Чегет, горные хребты
- **Реки и водопады** — Чегемские водопады, горные реки
- **Озёра** — Голубые озёра, высокогорные озёра
- **Ущелья** — Чегемское, Баксанское, Черекское
- **Флора** — альпийские луга, леса, цветы

Каждый подраздел — это визуальное путешествие с минимумом текста и максимумом атмосферы.

## Технический Стек

- **React + TypeScript** — основа
- **Vite** — сборка

- **Framer Motion** — плавные анимации
- **React Router** — навигация

---

## Ключевые Принципы

1. **Природа — главный герой.** Интерфейс не должен конкурировать с фотографиями.
2. **Меньше — лучше.** Минимум элементов, максимум воздуха.
3. **Плавность во всём.** Никаких резких переходов.
4. **Эмоция важнее информации.** Сначала почувствовать, потом узнать.
5. **Русский язык.** Весь контент на русском.
